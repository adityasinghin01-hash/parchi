## Other measured results
- Server hardening from two independent Codex reviews: reset race, ETA overflow, 1 MB body limit, failed-auth throttle (30/min per address), file permissions 600/700, idempotency key reuse with a different body returns 409, replay after reset refused, reroute to a delivered seller refused, unresolved items kept visible, `/read` proxy (503 when the reader is not connected). Known and left: judge key in the page URL (LAN demo), reject-replay ambiguity (needs a proposal id), SQLite/Temporal histories described above.
- Rate limit: 120 requests/min per install key (the app polls order, shop and lab status at once); bad keys 30/min.
- Data collected 23 Oct: 6 cities, labs 41 confirmed / 76 rows, 69 lab prices (69/69 prices found on the cited pages), 32 exact product links (23 with a price found), H1 50 + X 16 salts verified against the gazette PDFs.
- Kiro credits used for all Kiro jobs: see `kiro-cli` `/usage` (128 of 1,000 after 8 jobs).
- Jan Aushadhi matcher: 55.7% of 327 MIRAGE medicine mentions (ja_cov.py: 57.2%; the Swift matcher is stricter by design).
