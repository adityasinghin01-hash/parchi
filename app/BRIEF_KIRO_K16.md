## Build

Vision `VNRecognizeTextRequest` (.accurate, languageCorrection off, en-US; hi-IN as a second pass only if supported), keep each observation's bounding box, group boxes into lines by vertical overlap (top to bottom, left to right), pass each line to `PrintedParser`, map to `ReaderLine` (kind medicine/test, name, strength, quantity, schedule).
