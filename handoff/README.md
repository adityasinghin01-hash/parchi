## Tools and gotchas
- Server tests (MacBook): `cd ~/dev/parchi/server && .venv/bin/python -m pytest -q tests`. Workflow tests start a local Temporal test server (needs a normal shell, not a sandbox).
- iMac (Xcode, Swift, simulators, the real running server): `ssh imac` (login shell: use `zsh -l -c '...'`). Server there lives in `~/parchi/server` (running on :8000; keys in `~/parchi/server/data/*.key`; read them INSIDE the ssh command, never print them). Restart: `cd ~/parchi/server && bash stop.sh; bash start_all.sh` (idempotent). Copy server code there with `rsync -az --exclude .venv --exclude data --exclude __pycache__ --exclude .pytest_cache --exclude '*.db' --exclude '*.log' server/ imac:parchi/server/` (NO `--delete`). Engine/app builds: use a SCRATCH copy on the iMac (`~/parchi-<yourname>/`; `rsync -az --delete --exclude .build --exclude xcuserdata engine/ app/` into it is fine THERE), then `xcodegen generate` (always after an rsync of `app/`), `xcodebuild test -project Parchi.xcodeproj -scheme Parchi -destination 'platform=iOS Simulator,name=iPhone 17 Pro' -derivedDataPath ~/parchi-dd-<yourname>`. Live UI tests need `TEST_RUNNER_PARCHI_BASE_URL=http://localhost:8000 TEST_RUNNER_PARCHI_INSTALL_KEY=$(cat ~/parchi/server/data/sim_install.key) TEST_RUNNER_PARCHI_ADMIN_KEY=$(cat ~/parchi/server/data/admin.key)` set inside the ssh command.
